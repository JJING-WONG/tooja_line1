## 주의 사항

### 인증

- 투자자 코드는 문자열로 처리
- 로그인 후 새로운 CSRF 토큰 사용
- 투자자와 관리자 세션 분리
- 세션 만료 시 로그인 페이지로 이동
- 투자자 개인 데이터 쿼리는 `["investor", ...]` 키를 사용해 로그아웃 시 함께 정리

### API

- API 타입은 OpenAPI에서 생성한 타입을 우선 사용
- 투자자 잔액과 투자 여부는 서버 응답을 기준으로 처리
- 투자 가능 여부와 전체 투자 운영 상태를 구분

### 개발 원칙

- 기존 아키텍처 및 폴더 구조 유지
- Figma의 실제 디자인 화면을 기준으로 UI 구현
- 화면 아래의 초기 기획 설명은 구현 기준에서 제외
- 불필요한 추상화 및 라이브러리 추가 지양
- 기능 구현 후 테스트 및 PR을 거쳐 main에 병합
