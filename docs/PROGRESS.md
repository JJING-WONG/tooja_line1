# MALLAGE 개발 진행 상황

## 완료된 작업

- Vite + React + TypeScript 프로젝트 초기 설정
- Tailwind CSS 설정
- React Router 및 TanStack Query 설정
- 프론트엔드 아키텍처 설계
- OpenAPI 명세 동기화 및 타입 생성 설정
- Vite API 프록시 설정
- Axios 공통 인스턴스 구현
- 투자자 CSRF 토큰 발급 API 구현 및 테스트

## 현재 작업

투자자 로그인 및 세션 관리 구현

## 다음 작업

1. 투자자 로그인 API 구현
2. 로그인 후 CSRF 토큰 갱신
3. 투자자 세션 조회 및 복구
4. 로그아웃 기능 구현
5. 로그인 페이지 구현
6. 인증 기반 라우트 접근 제어

## 주의 사항

- 투자자 코드는 문자열로 처리
- 로그인 후 새로운 CSRF 토큰 사용
- 투자자와 관리자 세션 분리
- 세션 만료 시 로그인 페이지로 이동
