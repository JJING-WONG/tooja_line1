# MALLAGE 개발 진행 상황

## 완료된 작업

- Vite + React + TypeScript 프로젝트 초기 설정
- Tailwind CSS 설정
- React Router 및 TanStack Query 설정
- 프론트엔드 아키텍처 설계
- OpenAPI 명세 동기화 및 타입 생성 설정
- Vite API 프록시 설정
- Axios 공통 인스턴스 구현
- 투자자 CSRF 토큰 발급 API 구현 및 테스트
- 투자자 로그인·세션 조회·로그아웃 API 요청 함수 구현
- 투자자 로그인 페이지 UI 구현 (제공된 SVG 및 키컬러 적용)
- 투자자 로그인 화면 API 연결 및 로그인 응답의 새 CSRF 토큰을 세션 캐시에 저장
- 로그인 요청 중 중복 제출 방지 및 인증·CSRF·네트워크 오류 표시
- 투자자 세션 조회 및 새로고침 시 투자자 정보·CSRF 토큰 복구
- 로그인·투자 홈 라우트의 인증 상태 확인 및 접근 제어 (조회 중 대기, 통신 실패 시 재시도)
- 투자자 로그아웃 훅 구현 (CSRF 재발급·1회 재시도, 성공 시 투자자 캐시 정리 및 로그인 이동)
- 투자 홈에 간단한 로그아웃 버튼 연결 (요청 중 비활성화·실패 메시지 표시)

## 현재 작업

투자자 로그인 및 세션 관리 구현

## 다음 작업

1. 투자 홈 Figma 디자인 반영
2. 향후 추가할 투자자 페이지에 보호 라우트 적용
3. 실제 서버 로그인 및 세션 흐름 검증

## 주의 사항

- 투자자 코드는 문자열로 처리
- 로그인 후 새로운 CSRF 토큰 사용
- 투자자와 관리자 세션 분리
- 세션 만료 시 로그인 페이지로 이동
- 투자자 개인 데이터 쿼리는 `["investor", ...]` 키를 사용해 로그아웃 시 함께 정리
