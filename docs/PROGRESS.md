- D01은 `investmentStatus="PAUSED"` 전달 시 흰색 30% 덮개·중앙 170px 원본 아이콘·상단 일시중지 안내를 표시. 기본은 `RUNNING`이며 재연결 실패 표시는 접수 상태와 별도로 유지한다.
- 과거 기본 UI 브라우저 확인 기록은 최신 API 연결의 브라우저 검증 완료를 뜻하지 않는다.

## 3. API별 현황

기준: [OpenAPI](./openapi.json)의 HTTP 메서드 + 경로 및 `src/features/*/apis` 요청 함수·호출부. 아래 경로는 `/api/v1`을 생략했다. 타입은 [schema.d.ts](../src/apis/schema.d.ts)를 사용한다. 기존 번호는 유지하며 삭제된 #19는 이력으로 남기고 신규 API에 #23을 부여한다.

- **요청 함수 완료**: 요청 함수·생성 타입 사용 코드가 존재함. 최신 명세 변경에 따른 코드·주석·테스트 정합성 검증 완료를 뜻하지 않음.
- **화면 연동 완료**: 화면·훅에서 해당 함수를 실제 사용.
- **서버 기본 확인**: 기존 서버 확인 기록은 있으나 전체 상태·오류 검증은 미완료.

## 4. 확정된 동작·정책

### 투자자

- 한 팀에는 한 번만 투자 가능. 이미 투자한 팀은 P02에서 회색·실선, 기존 투자 금액 유지, 선택 불가.
- 참가자의 내 팀은 회색·점선·선택 불가. 운영팀에는 소속팀 제한이 없지만 이미 투자한 팀은 동일하게 차단.
- P03에서 내 팀·이미 투자한 팀에 직접 접근하면 홈으로 복귀. 투자 일시정지·잔액 소진 중에도 상세 소개 조회는 허용.
- 금액 버튼 7개는 유지하며 서버 `allowedAmounts`·팀 상태·전체 접수 상태로 투자 가능 여부 판단. 금액 미선택 시 금액·예상 잔액은 ‘-’.
- P02 막대는 투자액 비율. 전액 소진 시 전체 부스 회색·기존 투자액 유지. 운영팀 현황 카드의 소속은 ‘운영팀’, 하단 안내 문구 제외.
- P04 잔액은 거래 직후 잔액이 아닌 조회 시점 `currentBalance`. 없는 거래와 타인 거래는 동일한 접근 불가 안내.

### 투자 확정·인증

- 처리 중 버튼·Esc·배경 조작·로그아웃 요청 차단. 불확실한 결과에서는 새 투자 대신 기존 요청 결과 확인.
- 전송 전 투자자 ID·UUID v4 요청 키·본문만 `sessionStorage`에 보관. 토큰·로그인 코드는 저장하지 않으며, 저장 실패 시 전송하지 않음.
- 응답 유실 시 #11 확인. `SUCCEEDED`는 성공, `REJECTED`는 거절. `REQUEST_RESULT_NOT_FOUND`만 같은 키·본문으로 #8 재전송. 새 키 자동 재전송·무한 자동 재시도 금지.
- 보관 요청은 같은 투자자가 재로그인/새로고침하면 복구하며 다른 투자자에게 재전송하지 않음.
- HttpOnly 쿠키 인증 유지. 투자자·관리자 세션/CSRF/캐시를 분리하고 로그아웃 시 해당 역할의 캐시만 정리.

### 관리자·공통 표시

- ‘투자 중단’은 재개 가능한 `PAUSED`. 최종 마감·거래 취소·잔액 수정 기능이 아님.
- 투자자는 등록 시 100만원을 지급받으며 로그인 여부와 무관하게 집계에 포함. 화면 금액은 계산으로 대체하지 않고 실제 응답을 사용.
- A03 검색·표 헤더는 ‘이름’으로 표시하고 A04도 등록된 이름을 사용. API 필드명 `alias`는 유지하며 이름 수정 기능은 제공하지 않음. P02 중지 안내는 ‘지금은 투자가 일시정지되어 있어요’로 표시.
- 운영팀은 ‘운영팀’으로 표시. 미소진·소진 완료 상태는 서버 `spendingStatus`로 구분.
- A03 기본 상태 필터는 미소진, 전체는 파라미터 생략. 검색어 300ms 입력 대기·URL 유지. 별도 페이지네이션은 추가하지 않음.
- A02~A04 공통 현황 조회는 1초, A03 목록은 2초 주기. A04 상세는 별도 주기 없이 진입·포커스·재연결 시 갱신.
- 관리자 주기 조회는 숨김 탭·로그아웃·상태 변경 중 중단. 갱신 실패 시 기존 데이터 유지·같은 장애의 모달 반복 방지, `Retry-After` 준수.
- 표시 시각은 `Asia/Seoul`. 실제 Figma 화면을 기준으로 하며 하단 초기 기획 설명은 구현 기준에서 제외.

### D01 연동 시 유지할 기준

- 공동 순위는 동일 금액 기준 `1·1·3`, 전체 0원이면 모두 1위. 연결 시 서버 `rank` 사용.
- 순위 변화·투자 증가액은 이전 응답과 비교하고 `snapshotVersion`과 조회 시각 `asOf`를 구분.
- 현재 시안의 1위 막대는 트랙 675px 중 620px. 별도 결정 없이 100%로 바꾸지 않음. 강조 시간·순위 이동 효과는 필수 연동 범위와 구분.

기술 스택·폴더 구조·코딩 규칙은 [ARCHITECTURE.md](./ARCHITECTURE.md)와 [AGENTS.md](../AGENTS.md)를 따른다.
