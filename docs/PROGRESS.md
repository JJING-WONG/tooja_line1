## 1. 현재 우선순위

- D01 투자 일시정지 안내는 디자이너 수정본 미수령으로 보류. 수정본을 받은 뒤 별도 디자인 작업하며 임의로 추가하지 않음
- 기준 명세: `docs/openapi.json`, 생성 타입: `src/apis/schema.d.ts`

- 투자 확정은 응답 지연 시 동일 요청 키의 결과 확인을 우선하며 새 요청 키로 자동 재전송하지 않음

### 시안 데이터 사용 범위

- P03은 #6, P04는 #10 실제 응답을 사용한다. P03-M은 #8·#11, P05는 #9 실제 응답에 연결. A02는 #16·#20에 연결. A03은 #17에 연결. A04는 #18에 연결. D01은 시안 데이터 연결이 남아 있다.
- A03은 서버 count·items 및 필터를 사용하며 기본 필터는 미소진. 전체 선택은 상태 파라미터를 생략한다.
- A04는 URL의 investorId에 해당하는 실제 정보·최신순 거래를 표시하며 다른 투자자로 이동 시 이전 조회를 취소한다.
- 관리자 로그인·세션·로그아웃은 #12~#15에 연결. A02~A04 사이드바 시작·중단 버튼은 #20에 연결. D01 연결 상태·갱신 시각·변화 강조는 아직 서버 동작과 미연결.

## 3. API별 진행 현황

**전체 22개 · 요청 함수 완료 20개 / 미구현 2개 · 화면 연동 완료 18개**

- API 개수는 `docs/openapi.json`의 **HTTP 메서드 + 경로** 기준이다. 아래 경로에는 공통 접두사 `/api/v1`을 생략했다.
- 요청 함수: `완료`는 명세에 맞는 함수·타입 구현, `미구현`은 함수가 아직 없음을 뜻한다.
- 화면 연동: `완료`는 UI·훅에서 실제 요청을 사용함을 뜻한다. API 구현만 완료해도 연동 완료로 표시하지 않는다.
- 서버 검증: `기본 확인`은 기존 실제 서버 확인 기록이 있으나 모든 오류·상태 검증을 마치지는 않았다는 뜻이다. `미검증`은 확인 기록이 없다.
- **API 작업 후 해당 행·합계를 함께 갱신하고, 구현한 함수 이름을 기록한다.** 명세 변경 시 API 목록도 대조한다.

### 구현 위치 및 연동 원칙

관리자 인증 요청 함수 4개 구현 완료: 빌드·ESLint 및 로컬 Axios 어댑터로 경로·헤더·코드 문자열·응답·로그아웃·오류 전달·조회 취소 확인. 화면 연동과 실제 서버 검증은 미진행.

- 모든 API 함수 주석에 사용 화면(ID·화면명)과 호출 시점을 기록한다. 미연동 함수는 ‘사용 예정’으로 구분하고, 연결할 때 실제 사용처로 갱신한다.

- 인증 → `src/features/auth/apis/auth.api.ts`
- 투자자 정보·팀 조회 → `src/features/investor/apis/investor.api.ts`
- 투자 → `src/features/investment/apis/investment.api.ts` / 관리자 → `src/features/admin/apis` / 공개 조회 → `src/features/dashboard/apis`
- 아직 없는 API 파일은 해당 기능을 구현할 때 추가한다.
- 요청·응답 타입, 필터, CSRF·요청 키 등은 실제 명세를 따른다. 별도 기능이나 필드를 추측해 추가하지 않는다.
- 요청 함수 구현과 UI 사용 여부는 별개다. 중복 조회는 필요한 화면에서만 사용하며, 시안에 없는 기능은 임의로 연결하지 않는다.

## 6. 유지할 동작과 개발 기준

- 참가자는 자기 팀 선택 불가. 운영팀은 소속팀 제한 없음. 역할과 무관하게 이미 투자한 팀은 선택 불가

- P02 막대는 투자액 비율, 전액 소진 시 부스 전체 회색 및 기존 투자액 유지
- 운영 중지 시에도 팀 상세 조회는 허용
- HttpOnly 쿠키 인증을 유지하고 투자자·관리자 세션과 CSRF 토큰을 분리
- 투자자 개인 쿼리는 `["investor", ...]` 키로 관리하고 로그아웃 시 정리
- 기존 아키텍처·생성 타입·공통 Axios를 사용하고 불필요한 라이브러리나 추상화 추가 금지
- Figma의 실제 화면만 구현 기준으로 사용하며 하단 초기 기획 설명은 제외
- 영어 Anta·한글 Noto Sans KR 유지
